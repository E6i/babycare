# Baby Care · SuperMamy

تطبيق عربي لتنظيم رعاية الطفل: ملفات لأكثر من طفل، سجل يومي، متابعة النمو والتطعيمات والأدوية، تذكيرات، ومشاركة تقارير الرعاية.

تحليل البكاء يستخدم نموذج Keras عبر Python. النتائج احتمالية، والمشروع تعليمي ولا يقدم تشخيصًا طبيًا أو ادعاءً بدقة مثبتة سريريًا.

## التشغيل

اتبع [خطوات التشغيل](../README.md#getting-started): ثبّت متطلبات الواجهة، انسخ `.env.example` إلى `.env`، واضبط قاعدة بيانات محلية ومفتاح جلسات جديدًا. بعد تطبيق migrations شغّل `npm run dev` من مجلد `frontend`.

لتحليل الصوت، ثبّت متطلبات `ml/requirements.txt` في بيئة Python مستقلة واضبط `PYTHON_BIN`. مفاتيح DeepSeek وResend اختيارية ولا تُرفع إلى GitHub.

## المساهمة

استخدم بيانات وهمية فقط عند تجربة الملفات والتقارير أو تصوير الواجهات. لا تضف تسجيلات أطفال حقيقية أو ملفات قواعد بيانات أو مفاتيح خدمات إلى المستودع.
